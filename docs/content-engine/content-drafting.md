# Adapt a researched format into original content

Read the brand brief, target platform and the idea's evidence brief before drafting.
Preserve the researched sequence and mechanism while creating original wording,
examples, footage and audience-specific value. Do not copy a creator's script,
identity, claims or assets. Do not invent testimonials, statistics or experiences.

Use a concrete opening that creates the same type of curiosity or tension as the
reference and pays it off. Make the value clear, remove generic introductory
phrases, and use one natural CTA aligned with the account's goal. Write in the
brand's voice. If the evidence brief is missing, do not claim the draft is based on
verified research. Do not invent reference URLs or performance metrics.

Adapt to the actual target platform. A cross-platform adaptation is an untested
hypothesis unless references for that platform support it. Respect maxChars and
the requested output schema. For a text-post request, output publishable text only;
keep internal research notes and performance claims out of the public body.
A caption is not a produced Reel. If asked for a production brief, specify opening
visual, spoken hook, scene beats, on-screen text, payoff and required assets.

Before returning: check audience relevance, specific value, hook/payoff alignment,
originality, factual support, brand exclusions and platform limits. Never claim
that the adapted content will go viral. Drafts remain subject to the host's review
and publishing workflow.
