# Embedded fonts

All three typefaces are redistributed under the SIL Open Font License 1.1. The original license and copyright notices are retained alongside each font. Family aliases in the renderer avoid changing the original font binaries.

| Typeface | Role | Source | License file |
|---|---|---|---|
| Archivo Black Regular | Monumental statements, numerals, masthead | https://github.com/google/fonts/tree/main/ofl/archivoblack | `archivoblack-OFL.txt` |
| Instrument Serif Regular | Pull quotes | https://github.com/google/fonts/tree/main/ofl/instrumentserif | `instrumentserif-OFL.txt` |
| DM Sans variable, optical size and weight | Folios, captions, attribution, supporting text | https://github.com/google/fonts/tree/main/ofl/dmsans | `dmsans-OFL.txt` |

Downloaded from the Google Fonts repository on November 11, 2026. No runtime font network request is required. Fallbacks are Arial Black / sans-serif, Georgia / serif, and Helvetica Neue / Arial / sans-serif respectively. Code scenes use the system monospace stack.
