# Embedded fonts

Both fonts permit embedding under the SIL Open Font License 1.1. Unmodified upstream license texts are included alongside the font binaries. CSS uses distinct family aliases with system fallbacks.

| --- | --- | --- | --- |
| Anton Regular | Anton-Regular.ttf | SIL OFL 1.1, Anton-OFL.txt | https://github.com/google/fonts/tree/main/ofl/anton |
| Archivo Narrow variable, weights 400–700 | ArchivoNarrow-Variable.ttf | SIL OFL 1.1, ArchivoNarrow-OFL.txt | https://github.com/google/fonts/tree/main/ofl/archivonarrow |

Binary URLs: https://raw.githubusercontent.com/google/fonts/main/ofl/anton/Anton-Regular.ttf and https://raw.githubusercontent.com/google/fonts/main/ofl/archivonarrow/ArchivoNarrow%5Bwght%5D.ttf.
