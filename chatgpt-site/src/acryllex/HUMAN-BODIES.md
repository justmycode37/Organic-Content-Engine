# Explicit rigged human bodies

Any registered human model can use an authored rigged body without adding it to the fixed body catalogue:

```json
{"model":"human","params":{"bodySource":{"file":"/private/path/body.glb","sha256":"<64 hex digits>"},"height":1.8}}
```

Alternatively use `bodySource.url` with an HTTPS `.glb` URL. Supply exactly one file or URL. SHA256 is optional; a pin is recommended for reproducible remote identity. The Node asset preparer verifies supplied pins against fresh **and cached** bytes. Prepared bytes are content-addressed. Unpinned URLs retain a local digest pointer for offline reuse; clear that pointer deliberately to fetch a new version. Local files are reread on preparation, and changed bytes get a new content path. Keys include source kind/location and optional pin; browser preload replaces a cached template when its prepared path changes.

Only omission disables this parameter. Explicit `null`, `false`, malformed settings, missing files, failed downloads, checksum failures and unsuitable rigs are errors. They do not substitute Brian, Xbot or a cube. `params.body` and `bodySource` cannot be combined. An import overrides a registered `human-male`/`human-female` asset, including anatomical material/hair policy; that registration does not label the imported asset's sex.

The body must be a self-contained GLB2 (maximum128MiB) with embedded binary geometry and PNG/JPEG/WebP images in bufferViews or base64 data URIs. All mesh nodes must be skinned triangle meshes; rigid accessories need skinning before import. Skin weights must use dense float or normalized unsigned byte/short accessors. The joint hierarchy must sit outside mesh subtrees. External buffer/image URIs, SVG and separate `.gltf` dependencies are rejected. Compression extensions still need support in the existing GLTFLoader; this option does not install decoders.

Provide canonical `Hips`, `Spine`, `Neck`, `Head`, and both `Left`/`Right` `Shoulder`, `Arm`, `ForeArm`, `Hand`, `UpLeg`, `Leg`, `Foot`, `ToeBase` bone labels. The usual `mixamorig`, optional numeric suffix and colon prefix are understood by the existing rig. Extra spine/neck bones are supported; finger bones are optional. Canonical joints must form a coherent hierarchy, with nonzero limbs, normalized finite skin weights and one unambiguous bone per label. The authored bind body must be uprightY-up, feet below hips, face+Z, Left/Right at+X/-X, with positive uniform non-sheared rest transforms. Different bone-local rest axes and uniform source units are supported by HumanRig. No axis guessing, retarget label mapping, skeleton replacement or anatomical reshaping is attempted.

Visible standing height is normalized by one positive uniform scale. Default height is1.8m, explicit `figure:woman`1.68m, `figure:child`1.15m; explicit `height` wins. Source file names and registered anatomical sex/height do not infer import proportions. Default foot scale is1 to preserve authored feet; explicit existing foot/headScale controls remain authoritative. Imported bodies use scan-style `staticPoseBase:idle`, `staticFloor:none`, `ground:false`; explicit neutral poses, ground contact and keyed pose/IK controls remain available. Skin-based static settling remains limited to the bundled anatomical models. Existing alpha, named Hair sidedness, material/head/region tone, optional head accent and pose-corrective controls take the same instance path. Corrective fields only exist where the asset actually authors them; no missing data is synthesized.

Source body animation clips are ignored. Existing Xbot mocap or explicitly configured recorded motion drives the normalized body. Finger-free bodies work without creating capture finger frames; opt-in captured finger motion needs suitable target fingers. The constructor validates a disposable bind clone, keeping cached geometry/UV/skin/bind matrices/materials unchanged. Instances own their posed bones and converted materials. Contact/shape realism depends on the supplied asset and requested motion; valid import is not proof of a reference match or collision-free anatomy.
