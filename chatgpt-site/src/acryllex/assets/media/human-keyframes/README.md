# Experimental human motion keyframes

These AI-generated, undithered grayscale plates provide explicit first/end inputs for a continuous walk-to-sit motion experiment. The synthetic actor is fully clothed; both RGB frames use the same1164×670 canvas and a black background.

`walk.png` and `type.png` are source images, not animation frames from an adopted recreation. `provenance.json` records generation, global framing, file hashes and the remaining pose/density errors. The ending plate remains wider than the reference, so these inputs are experimental. A generated clip must preserve the actor/view, provide coherent motion, and pass a new reference comparison before adoption.

No model preset or renderer default is changed by these files.
