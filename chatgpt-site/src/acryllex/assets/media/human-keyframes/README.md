# Experimental human motion keyframes

These AI-generated, undithered grayscale plates provide explicit walking, backward-reaching and seated typing inputs for a continuous human-motion experiment. The synthetic actor is fully clothed; all RGB frames use the same 1164×670 canvas and a black background.

`walk.png`, `reach.png` and `type.png` are source images, not animation frames from an adopted recreation. `provenance.json` records generation, global framing, file hashes and remaining pose/density errors. The seated plate remains wider than the reference, and the reach hand extends too far left.

The first/end-only generation preserved identity and natural proportions but crouched too early and omitted the backward chair reach. Its full recreation trial was rejected. The middle frame explicitly supplies that missing action for a new controlled test. Intermediate poses, local density, contrast and timing still require comparison before adoption.

No model preset or renderer default is changed by these files. Original reference images and video are not included.
